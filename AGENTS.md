# AGENTS.md

Para cualquier IA que trabaje en este repositorio. Corto: enruta, no explica.

1. **Lee primero** [`README.md`](README.md) y la tabla de estado de
   [`spec/brutalist-interfaces-spec.md`](spec/brutalist-interfaces-spec.md).
2. **No decidas.** Las decisiones son del maintainer y viven en
   [`decisions/DECISIONS.md`](decisions/DECISIONS.md). Propón, marca `[propuesta]` o
   `DECISION` (decisión tuya dentro de un bosquejo), y pregunta.
3. **No reescribas la historia.** `DECISIONS.md` y las reacciones citadas no se editan: se
   añade con fecha y puntero.
4. **Clasifica lo que afirmas**: `observed / measured / estimated / ambiguous / unknown`
   para lo que viene de una referencia; `INFERENCE` y `DECISION` para lo tuyo. Si no lo
   sabes, escribe `UNKNOWN`.
5. **Un hogar por hecho.** Antes de crear un archivo, busca si el hecho ya tiene sitio.
6. **Referencias**: derechos desconocidos → estudio privado; las imágenes no se versionan.
   En modo inspiración se toman principios, no textos, marcas ni ilustraciones.
7. **Experimentos**: desechables; el maintainer juzga, el agente no puntúa. Verifica en
   navegador real y di qué **no** verificaste.
8. **Repositorio público**: no añadas contenido de proyectos privados ni rutas locales.
   Para experimentos, usa un brief neutro o inventado y decláralo.
