# references/ — third-party reference images

Captures of brutalist sites used to design and test the skill (DR5-5). **The images are
not versioned** (unknown rights, see [`.gitignore`](../.gitignore)); each contributor keeps
their own in `images/` locally. Only a description of each stays here. For images that can
be published, see [`examples/`](../examples/README.md), which uses original references made
in this repository.

| Local file | What it shows (observed) |
|---|---|
| `images/ref-35.png` | a collaborative-writing site: centered serif statement with numbered callouts, numbered columns, vertical sidebar, a barcode |
| `images/ref-36.png` | an artist-book fair site: typewriter-style navigation, a 3D tower of blocks with names |
| `images/ref-37.png` | an essay site: a ticker with arrows, square cells with soft embossed shapes, three columns |
| `images/ref-38.png` | a portfolio: a page-filling sentence with outlined italic words; white and yellow versions |
| `images/ref-39.png` | a lecture-series site: one word's italic letters scattered and skewed across a white page; small bold grotesk blocks in the corners; a grid of dates |
| `images/ref-40.png` | an art school's journal on a laptop mockup: electric blue on white, thin blue rules, filter columns with open and filled circles, a blurred blue blob, cards |
| `images/ref-41.png` | a studio's project page: a neo-grotesk wordmark filling the full width, thin ruled metadata rows, a large paragraph, two small text columns |
| `images/ref-42.png` | a type foundry's specimen: vertical wordmark, a ladder of weights with right-aligned abbreviations, a black block with giant white letters, spec tables, a quote |

#35–#38 were used to try the "sketches first, from images" format of
[`inspire`](../skill/brutalist/references/inspire.md) (see
[`docs/FINDINGS.md`](../docs/FINDINGS.md)); those sketches are not published. #39–#42 inspired the gallery in
[`examples/gallery/`](../examples/gallery/) (principles only; see A-5).

**Rights: unknown** for all of them → study only; do not publish, and do not copy their text,
marks or illustrations. To add a reference: save it in `images/` and add a row here with
what it shows and where it came from.
