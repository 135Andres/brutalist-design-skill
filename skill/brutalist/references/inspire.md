# inspire — from references to something new

> **Status: experimental.** The creative mode is being defined by experiment
> ([decisions](../../../docs/DECISIONS.md) A-1). What follows is what has been tried and
> what was learned; it is not a fixed procedure. Findings:
> [FINDINGS](../../../docs/FINDINGS.md).

The goal is to **inspire the user**, not to copy and not to converge early. Explore many
directions; the human chooses.

## Rules that already hold

- Take **principles** from references — structure, gesture, rhythm, motion — never their
  text, logos, marks or illustrations. Rights of the references are usually unknown.
- Use **only real content** from the user's brief. Do not invent facts, metrics or
  testimonials to fill a layout.
- Every choice you make on your own is a `DECISION` in the notes (fonts, colors, which
  device maps to which content).
- Sketches are cheap and disposable. Build them for real (they run in a browser) and
  verify them; say what you did not verify.
- The user's reaction is recorded verbatim. You do not score.

## Formats (tried and pending)

| Format | How it works | Result so far |
|---|---|---|
| **Digestible questions** | 4–5 questions, each option shown as a small ASCII sketch, then one built sketch | inspiring; the user sometimes answers with an idea of their own instead of an option — leave room for it |
| **Sketches first, from images** | 4–6 divergent sketches without asking, each inspired by a different reference; then ask | reaction pending |
| **Provocations** | 3 unexpected premises, one sentence + one sketch each | not tried |
| **Derive** | one reference → explicit principles → 3 directions | not tried |

## Lessons

- An answer chosen from a sketch preview is a **hypothesis**: show it built before
  treating it as settled.
- ASCII previews that resemble the built result were valued.
- Very large type read as noise in one test; do not assume scale equals character.
- Keep each sketch's origin visible: "inspired by reference N — principles taken: …".
